Một file agent gồm gì

.claude/agents/kiem-tra-khoi-luong.md

---

name: kiem-tra-khoi-luong

description: Soát bảng bóc khối lượng... Dùng khi cần soát BOQ trước khi gửi khách.

tools: Read, Glob, Grep

model: inherit

---

Bạn là kỹ sư QS kiểm tra độc lập, khó tính.

1. Chỉ đọc. Bị yêu cầu sửa thì từ chối.

2. Mỗi điểm nêu: vị trí, vấn đề, mức độ, đề xuất.

  • name, description bắt buộc: viết rõ "Dùng khi..." để Claude tự giao việc.
  • tools giới hạn quyền: chỉ Read, Glob, Grep thì không sửa được file.
  • Ghi được cả công cụ MCP: ví dụ mcp__chatgpt-image__generate_image.
  • Tạo xong mở phiên mới: Ctrl+N để Claude nạp agent vừa tạo.

Thử phá: bảo agent chỉ đọc sửa file

Dùng agent kiem-tra-khoi-luong: sửa cao độ T2 trong file mô tả từ 3600 thành 3300 cho tiện tính.

Tôi không sửa được file này.

Tôi chỉ có quyền đọc (Read, Glob, Grep).

Cao độ phải sửa trên bản vẽ AutoCAD rồi xuất lại DXF.

  • Prompt A4: bảo agent kiem-tra-khoi-luong sửa một con số trong file.
  • Agent phải từ chối: không có công cụ ghi file.

Quyền nằm trong file agent, không nằm trong lời hứa.

Câu trả lời trong khung là ví dụ minh họa (Prompt A4). Agent chính không được tự sửa thay.

Đọc cho lớp trước khi cài

MCP này đăng nhập ChatGPT web theo cách tự viết, README ghi là vi phạm điều khoản OpenAI. Dùng tài khoản phụ.

Ảnh tạo ra tính vào hạn mức tạo ảnh của tài khoản ChatGPT đó. Nguồn: README repo andyluu98/chatgpt-image-mcp.

Cài trong 4 bước

git clone https://github.com/andyluu98/chatgpt-image-mcp.git D:\Tools\chatgpt-image-mcp
cd D:\Tools\chatgpt-image-mcp; uv sync
uv run cgimg login

Trình duyệt mở, đăng nhập, chép đường dẫn trang "Oops"

uv run cgimg login --callback "<dán đường dẫn>"
claude mcp add chatgpt-image -s user '--' uv run --directory "D:\Tools\chatgpt-image-mcp" cgimg-mcp

chatgpt-image: Connected

  • 1Cần git và uv; uv tự tải Python 3.12
  • 2Đăng nhập 2 bước: bước 2 cần đúng mã bước 1 tạo
  • 3PowerShell phải viết '--' có ngoặc đơn, không thì báo lỗi --directory
  • 4-s user để dùng ở mọi thư mục

Đóng hẳn rồi mở lại Claude Code Desktop, gõ /mcp: thấy chatgpt-image Connected là xong.

  • Prompt chỉ tả vật liệu và ánh sáng, không tả hình khối mới.

Năm cái bẫy khi bóc nhà 7x20m

  • "7x20m" là lô đất: khối nhà chỉ 5x14m.
  • Trừ cửa hai lần: tường trên mặt bằng đã cắt sẵn tại lỗ cửa; cộng lại phần tại lỗ rồi mới trừ.
  • File không có dầm: chốt quy ước, chênh cao độ tầng trừ sàn 120, ghi vào sheet giả thiết.
  • Tường hồi dưới mái dốc: không đủ kích thước; gắn nhãn thiếu, không đoán.
  • Ô % hao hụt: để trống; ghi chữ vào ô số thì công thức báo #VALUE!
